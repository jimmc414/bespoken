# Malbolge Language Specification

## Overview

Malbolge is an esoteric programming language designed by Ben Olmstead in 1998. It was specifically created to be as difficult to program in as possible, making it one of the most challenging programming languages ever conceived.

The name "Malbolge" comes from Dante's Inferno, referring to the eighth circle of Hell.

## Key Features

### Ternary Arithmetic
- All operations use base-3 (ternary) arithmetic
- Values range from 0 to 59048 (3^10 - 1)
- All arithmetic is modulo 59049

### Self-Modifying Code
- Instructions encrypt themselves after execution
- The encryption uses a substitution cipher (XLAT2 table)
- Programs evolve as they run

### Position-Dependent Instructions
- The meaning of a character depends on its position in memory
- Characters are normalized using the XLAT1 table
- Normalized instruction = XLAT1[(position + ASCII_value - 33) mod 94]

### Minimal Instruction Set
Only 8 valid operations:

| Instruction | Mnemonic | Description |
|-------------|----------|-------------|
| j | set_data | Set data pointer to value at data pointer |
| i | input | Read character from input into accumulator |
| / | rotate_acc | Rotate accumulator right (ternary rotation) |
| * | rotate_mem | Rotate memory cell, apply tritwise op with accumulator |
| p | output | Output accumulator as character |
| o | nop | No operation |
| < | move_data | Increment data pointer |
| v | halt | Stop execution |

## Memory Model

### Registers
- **a (accumulator)**: Main data register (0-59048)
- **c (code pointer)**: Points to current instruction (0-59048)
- **d (data pointer)**: Points to current data cell (0-59048)

### Memory
- 59049 cells (3^10)
- Each cell holds a value 0-59048
- Initialized with program code at the start

## Instruction Details

### Ternary Rotation

The rotation operation works in base-3:

1. Convert number to 10-digit ternary
2. Rotate digits right by one position
3. Convert back to decimal

Example:
```
decimal: 123
ternary: 0000011120 (10 digits, base-3)
rotated: 0000001112
decimal: 41
```

### Tritwise Operation

The tritwise operation is like XOR but for ternary digits:

```
Truth table:
  0 1 2
0 1 0 0
1 1 0 2
2 2 2 1
```

Applied to each ternary digit of two numbers.

### Encryption (XLAT2)

After each instruction executes, the character at the code pointer is replaced:

```
encrypted_char = XLAT2[original_char - 33]
```

This makes the program self-modify as it runs.

## Execution Cycle

1. Read instruction at position `c`
2. Normalize instruction using position-dependent table
3. Execute normalized instruction
4. Encrypt instruction at position `c`
5. Increment `c` and `d` (modulo 59049)
6. If instruction was 'v', halt; otherwise repeat

## Programming Challenges

### Why Malbolge is Difficult

1. **Position Dependency**: You can't just write instructions - you must find characters that normalize to the right instruction at each position

2. **Self-Modification**: Programs change as they run, making behavior hard to predict

3. **Limited Operations**: Only 8 operations, no direct arithmetic

4. **Ternary Math**: Unusual number system

5. **No Direct Control Flow**: No jumps or loops (though self-modification can create them)

## Historical Notes

- First "Hello World" program: Not written until 2000 (2 years after language creation)
- Written using a beam search algorithm, not by hand
- The first Malbolge program written by a human came years later
- Malbolge programs are typically generated by computers, not written directly

## Example Programs

### Simple Halt
```
v  (if 'v' normalizes to halt at position 0)
```

### Theoretical Hello World Structure
Due to position-dependency and self-modification, a real "Hello World" program would be hundreds of characters of seemingly random ASCII, generated by a search algorithm.
